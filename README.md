# Taaaaf Couture

Static home page for the Taaaaf Couture abaya store, built ahead of the Shopify conversion.

- `index.html` — home page (HTML, CSS and JS in one file; sections are labelled with the Shopify section they map to)
- `images/` — temporary images cropped from the brand's Instagram, to be replaced with the final product photography

Preview locally:

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.
